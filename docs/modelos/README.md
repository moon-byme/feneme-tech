# Modelos oficiais do Feneme

Referência do catálogo FT-51 (Jira), baseado nos três arquivos enviados pela professora.

| Modelo | Onde usar | Arquivo |
|---|---|---|
| 1 — História de Usuário | Descrição de Story no Jira | [MODELO_HISTORIA_DE_USUARIO.md](MODELO_HISTORIA_DE_USUARIO.md) |
| 2 — Bug | Descrição de issue do tipo Bug no Jira | [MODELO_BUG.md](MODELO_BUG.md) |
| 3 — Pull Request | Preenchido automaticamente ao abrir PR no GitHub | [../../.github/PULL_REQUEST_TEMPLATE.md](../../.github/PULL_REQUEST_TEMPLATE.md) |

## Regras de uso

- Os modelos são exemplos vazios: não marque checklists como concluídos sem evidência.
- Bug real deve ser registrado como issue do tipo Bug, não como Task.
- Cite a chave do Jira (FT-XX) no título do PR e no nome da branch, por exemplo `feature/ft-54-login-motorista`.
- O PR só deve ser integrado depois da aprovação de outra pessoa (Q-04) e do CI sem falhas.
